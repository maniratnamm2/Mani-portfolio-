# Mani Portfolio
## Overview
This repository contains my personal portfolio website, created to present my professional profile, engineering leadership experience, and major project contributions in a clear and modern format. The site is designed to reflect both technical depth and product-focused thinking.
## Description
The portfolio highlights my journey as a technology leader, including experience building scalable, secure, and accessible digital platforms. It showcases key achievements such as leading large-scale mobile banking engineering initiatives, driving WCAG-compliant accessibility programs, strengthening security and transaction reliability, and adopting AI-assisted development with automated quality checks.
The website is fully responsive and optimized for smooth viewing across devices, providing recruiters, hiring managers, and collaborators with a concise view of my background, skills, and impact.
## Features
- Clean and professional single-page portfolio layout  
- Responsive design for desktop, tablet, and mobile  
- Sections for profile, experience, skills, and achievements  
- Emphasis on accessibility, usability, and readability  
- Lightweight implementation for fast loading
## Tech Stack
- HTML5  
- CSS3  
- JavaScript 
## Project Structure
- `index.html` – Main webpage structure and content  
- `mani.js` – Client-side interactions and dynamic behavior  
- Assets (images/icons/fonts) – Visual and branding resources
